# Macie

A native macOS menu bar app: screenshots on a line you can note, group and paste into AI chats, clipboard history, a file wheel, window snapping, chrome app icons and a Liquid Glass dock.

**[Download the latest version](https://github.com/inverta-group/macie/releases/latest)**

Requires macOS 26 on Apple silicon. Macie updates itself; every update is signed and notarized by Apple.

This repository holds releases only.
